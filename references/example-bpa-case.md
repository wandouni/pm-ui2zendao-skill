# 示例：BPA 案例管理页

## 输入（客户原始描述）

> 支持 bpa 文件上传，bpa 上传完成后案例管理表格生成一条新的记录，结合 bpa 文件名+上传时间形成自动生成案例的名称。bpa 文件案例以表格形式展示，表格列包括序号、案例名称、案例状态（含未解析、解析中、解析完成、解析并选择完成、解析失败）、创建日期、创建人、操作列。操作列包括编辑（编辑案例名称）、另存为、删除案例（二次删除确认）、下载（含下载当前 bpa 文件、下载 bpa 解析后的物理模型文件集合）。点击案例名称，如果案例已经解析完成，则进入【物理模型查看页面】，如果案例状态为其他状态，则进入【物理模型解析监控页面】。

## 输出需求文档

```
BPA 案例管理页 — 界面需求规格
版本：v1.1
================================================================================
1 标题
  显示文字「BPA 案例管理」

2 工具栏
  位于标题下方，整体右对齐；左侧为【列设置】，右侧为【上传 BPA 文件】
  2.1 【上传 BPA 文件】
    点击弹出系统文件选择器，限制类型 .dat .bpa；上传中显示进度提示，失败显示错误提示；成功后【案例列表】顶部自动插入新记录，无需刷新
    2.1.1 案例名称自动生成规则：BPA 文件名（去扩展名）+ 上传时间（yyyy-MM-dd HH:mm），示例：220kV_夏大方式_2025-06-15 14:32
  2.2 【列设置】
    点击弹出列设置面板；非固定列支持显隐勾选和拖拽排序；固定列不可操作；提供【重置】和【全部显示】快捷操作
  2.3 【批量删除】
    仅在勾选一条或多条记录后出现；点击弹出二次确认弹窗，文案「删除后不可恢复，确认删除已选 {N} 条案例？」；【确认删除】在右，【取消】在左

3 【案例列表】
  名称列固定左侧，操作列固定右侧，中间列横向滚动；固定列与滚动区之间显示阴影，滚动到边界时阴影消失
  3.1 勾选
    每行左侧复选框；支持全选/反选
  3.2 序号
    自动递增，不可编辑；固定左侧
  3.3 案例名称
    固定左侧；表头带文本搜索框
    3.3.1 状态为「解析完成」「解析并选择完成」：可点击，跳转【物理模型查看页面】
    3.3.2 状态为「未解析」「解析中」「解析失败」：可点击，跳转【物理模型解析监控页面】
  3.4 案例状态
    表头带枚举下拉筛选；标签样式展示，五种状态：未解析 / 解析中 / 解析完成 / 解析并选择完成 / 解析失败
  3.5 创建日期
    格式 yyyy-MM-dd HH:mm；表头带升/降序排序，默认降序
  3.6 创建人
    纯文本展示，无筛选
  3.7 操作
    固定右侧；按钮从左至右：【编辑】【解析】【另存为】【删除】【下载】
    3.7.1 【编辑】：案例名称列原地变为输入框，回车或失焦保存，ESC 取消
    3.7.2 【解析】：触发重新解析；状态为「解析中」时置灰不可点击
    3.7.3 【另存为】：弹窗预填名称（原名称 + 「_副本」），确认后【案例列表】顶部新增记录，同时复制关联解析结果数据，状态继承原案例
    3.7.4 【删除】：二次确认弹窗，文案「删除后不可恢复，确认删除案例「{案例名称}」？」；【确认删除】在右，【取消】在左
    3.7.5 【下载】：展开下拉菜单；【下载当前 BPA 文件】始终可用；【下载物理模型文件集合】仅「解析完成」「解析并选择完成」时可点击，其余置灰提示「请等待解析完成」
  3.8 分页器
    位于【案例列表】右下角；含条数统计、每页条数切换（10 / 20 / 50）、页码导航、跳转输入框
================================================================================
```
